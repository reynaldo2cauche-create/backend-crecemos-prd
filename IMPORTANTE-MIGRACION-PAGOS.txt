  Opción 1 - Con phpMyAdmin:
    1. Abre phpMyAdmin (http://localhost/phpmyadmin)
    2. Selecciona la base de datos "crecemos_website"
    3. Ve a la pestaña "SQL"
    4. Copia y pega el contenido de add-desglose-to-pagos.sql
    5. Haz clic en "Ejecutar"

  Opción 2 - Desde MySQL Workbench:
    1. Abre MySQL Workbench
    2. Conecta a tu servidor local
    3. Abre el archivo add-desglose-to-pagos.sql
    4. Ejecuta el script

  Opción 3 - Desde la terminal:
    mysql -u root -p crecemos_website < migrations/add-desglose-to-pagos.sql

PAGOS REGULARES (Enero-Junio, Agosto-Noviembre):
  1. Ve a "Empleados"
  2. Clic en el icono verde $ del empleado
  3. Selecciona mes, año y fecha de pago
  4. Se registra 1 pago tipo "sueldo"

PAGOS CON GRATIFICACIÓN (Julio, Diciembre):
  1. Ve a "Gratificaciones"
  2. Selecciona el periodo (julio o diciembre) y año
  3. Clic en "Calcular"
  4. Clic en "Registrar" para cada empleado
  5. Se registra 1 SOLO PAGO tipo "sueldo_con_gratificacion" que incluye:
     - Sueldo base
     - Gratificación 25%
     - Monto total

HISTORIAL DE PAGOS:
  • Muestra TODOS los pagos registrados
  • Para pagos con gratificación, muestra el desglose:

    💰 S/ 1,500.00
       Sueldo: S/ 1,200.00
       Gratificación: S/ 300.00

  ✅ VERIFICACIÓN POST-MIGRACIÓN
═══════════════════════════════════════════════════════════════════

Después de ejecutar la migración:

1. Verifica en phpMyAdmin que las columnas existan:
   SELECT * FROM INFORMATION_SCHEMA.COLUMNS
   WHERE TABLE_NAME = 'pagos'
   AND COLUMN_NAME IN ('montoSueldo', 'montoGratificacion', 'mes', 'anio');

2. Reinicia el backend:
   npm run start:dev

3. Prueba registrar un pago con gratificación:
   - Ve a Gratificaciones
   - Calcula para julio o diciembre
   - Registra un empleado
   - Ve al Historial de Pagos
   - Deberías ver 1 pago con el desglose
